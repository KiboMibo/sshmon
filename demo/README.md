# Демо-запись

Сценарий, которым собран [`demo.gif`](demo.gif) из README.

sshmon показывает данные только с живых SSH-хостов, поэтому демо поднимает
временный флот из трёх одноразовых SSH-контейнеров (`web1`/`db1`/`cache1`) и
записывает интерфейс через [vhs](https://github.com/charmbracelet/vhs). Никаких
реальных серверов — только контейнеры на локальной Docker-сети.

## Пересобрать GIF

```sh
bash demo/record.sh
```

Нужен только Docker. Скрипт всё делает в контейнерах и убирает за собой
(бинарник sshmon и контейнеры флота — во временной папке/сети).

## Файлы

| Файл | Назначение |
| --- | --- |
| `record.sh` | оркестратор: сборка sshmon → флот → запись vhs → `demo.gif` |
| `demo.tape` | сценарий vhs (какие экраны и клавиши показываем) |
| `config.yaml` | демо-конфиг sshmon для флота (пароль/insecure — только для демо) |
| `sshd/` | образ одноразового SSH-сервера с фейковыми сервисами и логами |

Что показывает запись: **Fleet** (серверы по группам, живые метрики) →
**Dashboard** (CPU/RAM/диски/IO/сеть + порты + поток логов) → **Ports** →
полноэкранные **Logs** → **Help**.
