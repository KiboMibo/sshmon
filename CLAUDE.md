# CLAUDE.md — карта репозитория sshmon

TUI-мониторинг Linux-серверов по SSH без агентов: сбор метрик одним `exec`'ом,
история в SQLite, чат с LLM и MCP-сервер на stdio. Go, без cgo.

## Структура

| Путь | Что внутри |
| --- | --- |
| `cmd/sshmon` | точка входа: флаги, первый запуск, запуск сборщика/TUI/MCP. Весь жизненный цикл в `run() error` — никаких `os.Exit` из хелперов |
| `internal/config` | чтение и запись `config.yaml`, шаблон, импорт из `~/.ssh/config`, проверка прав на секреты |
| `internal/sshx` | SSH-транспорт: один клиент на сервер, переиспользование соединения, host-key, passphrase, потоковые сессии |
| `internal/collect` | сборщик: опрос по таймеру, парсинг `/proc`/`df`/`ss`, `Snapshot()`, подписки, диагностика, логи (`LogStream`, `LogBuffer`) |
| `internal/history` | SQLite (`modernc.org/sqlite`, WAL, одно соединение): запись точек, минутные агрегаты, ретеншен, запросы для графиков |
| `internal/tui` | bubbletea-модель и все экраны: Fleet, Dashboard, Processes/Ports/Docker, History, Logs, оверлеи (чат, поиск, палитра, справка, passphrase). Самый большой пакет — режется постепенно, см. `docs/architecture/0005-*` |
| `internal/llm` | клиенты OpenAI и Anthropic для чата |
| `internal/mcpsrv` | JSON-RPC 2.0 по stdio, инструменты `list_servers` / `get_metrics` / `get_issues` / `tail_log` |
| `internal/setup` | интерактивный выбор хостов из `~/.ssh/config` при первом запуске |
| `internal/buildinfo` | единственный источник версии (сверяется с тегом в релизном workflow) |
| `demo/` | сценарий записи `demo.gif` на одноразовых контейнерах. `demo/config.yaml` намеренно небезопасен и не является шаблоном |
| `docs/architecture/` | ADR: принятые архитектурные решения |

Зависимости идут сверху вниз: `tui → collect → sshx`. Обратных рёбер нет,
`tui` не должен импортировать `sshx` (транспортные типы и sentinel-ошибки
переопубликованы в `collect`).

## Сборка и тесты

```sh
go build ./...
go test ./...
go test -race ./...       # collect, LogBuffer и sshx многопоточные
go vet ./...
gofmt -l .                # должно быть пусто
```

Версия Go — из `go.mod`. CI (`.github/workflows/ci.yml`) гоняет gofmt, vet,
build, test, test -race и отдельной джобой govulncheck.

## Соглашения

- **Пользовательские строки и комментарии — по-русски.** Идентификаторы и
  имена тестов — по-английски.
- **Комментарий объясняет «почему», а не «что».** Очевидный код не
  комментируем.
- **Тесты лежат рядом с кодом** (`foo.go` → `foo_test.go`), в одном пакете.
  Табличные тесты предпочтительны; SSH и сеть подменяются интерфейсами
  (`collector` в `mcpsrv`, `logStreamer`/`dashboardSource` в `tui`).
- **Минимальные правки.** Не переписывать соседний код «заодно», не добавлять
  зависимости без нужды: `go.mod`/`go.sum` трогают отдельным решением.
- **Read-only по отношению к серверам.** sshmon ничего не ставит и не меняет
  на хостах; любая новая команда должна быть только чтением.
- **Секреты** не логируются, не пишутся в историю и не попадают в MCP-ответы.
