## Ограничение прогона (важно)

Go-тулчейн недоступен: `go.mod` требует 1.26.5, в контейнере 1.24.7, сеть до `proxy.golang.org`/`dl.google.com` закрыта; на машине пользователя Go нет.
**Что доступно:** `gofmt` (синтаксическая проверка парсингом) + чтение кода.
**Что недоступно:** `go build`, `go test`, `go vet`.
**Договорённость с пользователем:** правки уходят веткой + PR, вердикт даёт GitHub Actions CI (gofmt/vet/build/test/govulncheck). Ни одна волна не считается зелёной до зелёного CI.
