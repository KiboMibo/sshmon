# Архитектурные решения (ADR)

Здесь фиксируются решения, принятые в sshmon: почему сделано так, а не иначе,
и чем за это платим. Формат каждой записи — контекст → решение → последствия
→ альтернативы. Записи не редактируются задним числом: устаревшее решение
помечается статусом и заменяется новой записью.

| # | Решение |
| --- | --- |
| [0001](0001-manual-mcp-protocol.md) | Протокол MCP (JSON-RPC 2.0 по stdio) реализован вручную, без Go SDK |
| [0002](0002-pure-go-sqlite.md) | Pure-Go SQLite `modernc.org/sqlite` вместо cgo-биндингов; WAL и одно соединение |
| [0003](0003-ssh-connection-reuse.md) | Один SSH-клиент на сервер; соединение сбрасывается только при транспортной ошибке |
| [0004](0004-adaptive-single-layout.md) | Единая адаптивная раскладка TUI вместо режимов wide/narrow и отказ от внешней рамки |
| [0005](0005-tui-package-split-deferred.md) | Разрезание `internal/tui` на подпакеты принято, но отложено до зелёного CI |
