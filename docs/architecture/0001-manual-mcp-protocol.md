# ADR-0001. Протокол MCP реализован вручную, без Go SDK

**Статус:** принято · **Дата:** 2026-08-01 (фиксация ранее принятого решения)
**Код:** `internal/mcpsrv/mcpsrv.go`

## Контекст

sshmon должен отдавать метрики локальному LLM-агенту по Model Context
Protocol. Транспорт по спецификации — stdio, поверх него JSON-RPC 2.0. Нужен
минимум: `initialize`, `ping`, `tools/list`, `tools/call` с четырьмя
инструментами (`list_servers`, `get_metrics`, `get_issues`, `tail_log`).

sshmon — однобинарный CLI без cgo, который ставят через `curl | sh`. Размер
бинарника и число зависимостей — заметная часть его ценности. Официальный Go
SDK для MCP на момент решения был молодым, тянул за собой собственную модель
сессий и менял API между версиями.

## Решение

Реализовать серверную часть MCP самостоятельно на `encoding/json`:

- цикл `loop(io.Reader, io.Writer, collector)` читает NDJSON построчно
  (`bufio.Scanner`, буфер 1 МБ) и пишет ответы `json.Encoder`;
- поддерживается ровно то подмножество спецификации, которое использует
  агент; неизвестный метод → `-32601`, битый JSON → `-32700` с `id: null`;
- версия протокола эхом возвращается из `initialize` (дефолт `2025-03-26`),
  так что сервер не спорит с клиентом о версии;
- ошибки инструмента отдаются не как ошибка JSON-RPC, а как результат с
  `isError: true` — этого требует спецификация MCP для tools/call.

## Последствия

- Ноль дополнительных зависимостей, весь протокол — 222 строки.
- `loop` и `handle` тестируются на `strings.Reader`/`bytes.Buffer` и фейковом
  `collector`, без сети и без SSH: 9 тестов покрывают протокол целиком.
- Расширение спецификации (resources, prompts, streaming) придётся писать
  руками; сейчас их нет и они не нужны.
- Риск разъезда со спецификацией MCP при её развитии. Смягчение: набор
  методов минимален, а версию диктует клиент.

## Альтернативы

- **Официальный MCP Go SDK.** Дал бы полноту спецификации и совместимость по
  умолчанию, но добавил бы зависимость с нестабильным API ради четырёх
  инструментов. Отклонено по соотношению «объём кода / объём зависимости».
- **HTTP+SSE вместо stdio.** Потребовал бы слушать порт и решать вопрос
  аутентификации; для локального дочернего процесса агента это чистый минус
  по безопасности (см. раздел «Безопасность» в README).
